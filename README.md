# Municipal Services Reporting Application

## Overview
A user-friendly Windows Forms application built on .NET Framework that allows citizens to report municipal issues and service requests efficiently.

## Features
- **Main Menu Interface** with intuitive navigation
- **Issue Reporting Form** with comprehensive data collection
- **User Engagement Features** including progress tracking
- **Data Management** using appropriate data structures

## System Requirements
- **OS**: Windows 7 or later
- **.NET Framework**: Version 4.7.2 or higher
- **RAM**: Minimum 2GB
- **Storage**: 50MB available space

## Installation
1. Ensure .NET Framework 4.7.2 or later is installed
2. Download and extract the application files
3. Double-click `MunicipalServicesApp.sln` to open in Visual Studio

## Building and Running
### Visual Studio:
1. Open the solution file
2. Select **Build** > **Build Solution** (Ctrl+Shift+B)
3. Press **F5** to run

### Command Line:
```bash
msbuild MunicipalServicesApp.sln
cd bin\Debug
MunicipalServicesApp.exe
```

## Usage
1. Launch the application
2. Click "Report Issues" from the main menu
3. Complete all required fields
4. Optionally attach supporting files
5. Submit your report
